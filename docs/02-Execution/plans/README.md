## Findings considered and rejected (do not re-audit)

- **"Unescaped ESPN team color → XSS" (SEC-01 / period-intro color attribute):**
  REJECTED — false positive. `normColor()` at `period-intro.js:35-39` is a strict
  hex whitelist (`/^[0-9a-fA-F]{6}$/` or `{3}`, else a constant fallback); the value
  reaching `style="--c:…"` is always a valid `#hex` or the fallback. No injection path.
- **Delete orphan files (Copa.js, copa-score.js, wizards-score.js, fba-shipments.js,
  assets/CAPA-DE-FUNDO.png):** REJECTED — they are untracked (not in git history, so
  no repo/history bloat) and are kept on purpose per project decisions (Copa.js is a
  separate app; `fba-shipments.js` scaffolds the approved-but-unbuilt "FBA Envios"
  feature). Not dead code to delete.
- **Extract the ~1266-line inline `<script>` into a module:** NOT RECOMMENDED now —
  L effort, MED-HIGH risk, no tests, and it contradicts the `CLAUDE.md` rule
  "NÃO reescrever; evoluir incrementalmente". Revisit only after Plan 001 exists.
- **Deduplicate `esc`/`byId`/`nfmt` across files into `utils.js`:** REJECTED — in a
  no-module vanilla app this adds script load-order coupling for three trivial
  functions; risk > reward.
- **"Auto-inserted rows stamped 'Ok'/green assert manual verification that never
  happened" (2026-07-02 audit):** REJECTED — by design. The maintainer explicitly
  requested the auto-"Ok" with the green "Bom" style on 2026-07-02 (see BUG-006 in
  `README.md`). Do not re-report; revisit only if the maintainer asks to
  distinguish auto vs. manual rows.

  visible text uses `state.periodLabel` ("1º TEMPO") but the aria-label re-derives
